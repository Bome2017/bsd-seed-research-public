# Exact symbolic 2-isogeny descent for the 62a1 prime-twist family

Date: 2026-08-22  
Scope: the two isogeny-Selmer groups only  
Status: complete derivation, not yet independently reviewed  

This note proves the frozen Run013 descent target. It does not use analytic
rank, BSD, Tamagawa numbers, periods, or prior-art claims.

## 1. Statement and conventions

Let `q` be a positive rational prime such that

```text
q != 2,31,
q == 5 (mod 8),
(q/31) = -1.
```

The stronger definition of `F_62` also imposes `q` coprime to `3`,
`v2(#62a1(F_q))=2`, and `a_q != 0`. None of those three additional
conditions is used in this descent.

Use

```text
E_q:   y^2 = x^3 - 15*q*x^2 + 64*q^2*x,
E'_q:  y^2 = x^3 + 30*q*x^2 - 31*q^2*x.
```

The map `phi_q:E_q -> E'_q` has kernel generated by `(0,0)`, and
`hat_phi_q` is its dual. We use the orientation fixed in `TARGET.md`:

```text
phi_q(x,y) = (y^2/x^2, y*(64*q^2-x^2)/x^2),

hat_phi_q(X,Y)
  = (Y^2/(4*X^2), Y*(-31*q^2-X^2)/(8*X^2))
```

away from the kernels. These are the standard formulas for
`y^2=x^3+a*x^2+b*x`; the quotient coefficients are `-2*a` and
`a^2-4*b`. Substituting `a=-15*q,b=64*q^2` gives exactly `E'_q` and fixes
which Kummer cubic belongs to each Selmer group.

We then use the coverings

```text
C_phi(q,d):
    n^2 = d*u^4 + 30*q*u^2*v^2 - (31*q^2/d)*v^4,

C_dual(q,d):
    n^2 = d*u^4 - 15*q*u^2*v^2 + (64*q^2/d)*v^4.
```

The result proved below is

```text
Sel^(phi_q)(E_q/Q) = {1,-31,q,-31*q},
Sel^(hat_phi_q)(E'_q/Q) = {1}.
```

All equalities are in `Q*/Q*2`.

## 2. Kummer-cover equivalence and support

For

```text
A: y^2 = x^3 + a*x^2 + b*x
```

with rational point `(0,0)`, the usual Kummer map for the quotient isogeny is

```text
alpha_A(O)       = 1,
alpha_A((0,0))   = b,
alpha_A((x,y))   = x             if x != 0,
```

modulo squares. For `d in Q*/Q*2`, the covering

```text
n^2 = d*u^4 + a*u^2*v^2 + (b/d)*v^4                         (2.1)
```

has a point over a field `K` if and only if `d` belongs to the local Kummer
image. Indeed, if `v != 0`, then

```text
x = d*u^2/v^2,
y = d*u*n/v^3
```

is a point on `A`; the cases `v=0`, `u=0`, and `u*n=0` give the identity or
2-torsion limits. Conversely, reversing this substitution gives (2.1).

For `E_q` and `E'_q`, the primes of bad reduction and the prime dividing the
isogeny degree are contained in

```text
S = {2,31,q}.
```

Indeed, for `y^2=x^3+a*x^2+b*x` one has
`Delta=16*b^2*(a^2-4*b)`, and here

```text
Delta(E_q)  = -2^16 * 31   * q^6,
Delta(E'_q) =  2^14 * 31^2 * q^6.
```

At every odd good prime outside `S`, the local Kummer image is the
unramified subgroup of `Q_p*/Q_p*2`. Therefore a global Selmer class has even
valuation outside `S`. Every candidate has a unique representative

```text
d = (-1)^s * 2^e * 31^f * q^g,       s,e,f,g in {0,1}.       (2.2)
```

Thus the ambient group `Q(S,2)` has exactly 16 elements. At good primes
outside `S`, every class in (2.2) is unramified, so those places impose no
further condition.

For completeness, the good-prime assertion does not hide a numerical
assumption. If `p` is odd and both curves have good reduction, an isogeny of
degree 2 induces an isomorphism on the formal groups because its degree is a
`p`-adic unit. Hence its local cokernel is the corresponding cokernel on the
finite groups over `F_p`. The source and target curves are isogenous and
therefore have the same number of `F_p`-points; the rational kernel has order
2, so the finite cokernel also has order 2. Its Kummer image is unramified.
The unramified subgroup of `Q_p*/Q_p*2` also has order 2, so the two groups
are equal. The same argument applies to the dual isogeny.

## 3. The `phi_q` local images

Here the Kummer map is the `x`-coordinate map on

```text
E'_q: y^2 = x*(x-q)*(x+31*q).
```

### 3.1 Infinity

The rational 2-torsion points have Kummer classes

```text
1, -31, q, -31*q.
```

Since `q>0`, these include both real squareclasses. Hence

```text
im(alpha_phi,infinity) = R*/R*2.
```

### 3.2 The prime 2

**Lemma 3.2.** If `q == 5 (mod 8)`, then

```text
im(alpha_phi,2) = {1,q} = {the Q_2 squareclasses 1 and 5}.
```

**Proof.** Consider a `Q_2`-point on `C_phi(q,d)`. Replace `d` by a local
representative `2^e*delta`, where `e in {0,1}` and `delta` is odd. By the
weighted scaling `(u,v,n) -> (lambda*u,lambda*v,lambda^2*n)`, take
`u,v in Z_2` with at least one of them odd.

First suppose `e=1`. Multiplying the covering equation by 2 gives

```text
2*n^2 = 4*delta*u^4 + 60*q*u^2*v^2
        - 31*q^2*delta^(-1)*v^4.                              (3.1)
```

If `v` is odd, the right side of (3.1) has valuation zero, whereas the left
side has odd valuation. If `v` is even, then `u` is odd; in the original
covering equation the three terms have valuations respectively `1`, at
least `3`, and at least `3`. The right side has valuation exactly one and
cannot be a square. Thus `e=1` is impossible.

Now suppose `d` is odd. If exactly one of `u,v` is odd, reduction modulo 8
shows that the right side is congruent to `d`; hence solubility requires
`d == 1 (mod 8)`. If both are odd, use

```text
u^4 == v^4 == 1                 (mod 16),
30*q*u^2*v^2 == 6               (mod 16),
-31*q^2/d == 9*d^(-1)           (mod 16).
```

The right side is therefore

```text
d + 6 + 9*d^(-1)                (mod 16).
```

It is `12 (mod 16)` when `d == 3 or 7 (mod 8)`, which is not a square
modulo 16. Consequently an admissible odd `d` has squareclass `1` or `5`.

Both classes occur: `d=1` has the point at `v=0`, and `d=q` has
`u=v=1,n=0`. This proves the lemma. QED

### 3.3 The prime 31

The four rational torsion classes

```text
1, -31, q, -31*q
```

already exhaust `Q_31*/Q_31*2`: `q` is a nonsquare unit by hypothesis, and
`-31` has odd valuation. Hence

```text
im(alpha_phi,31) = Q_31*/Q_31*2.
```

### 3.4 The prime `q`

Because `q == 1 (mod 4)`, quadratic reciprocity gives

```text
(-31/q) = (q/31) = -1.                                         (3.2)
```

Thus `-31` is a nonsquare unit in `Q_q`, while `q` is a uniformizer. The
same four rational torsion classes exhaust `Q_q*/Q_q*2`, so

```text
im(alpha_phi,q) = Q_q*/Q_q*2.
```

### 3.5 Global intersection for `phi_q`

Only the place 2 cuts down (2.2). Since

```text
-1 == 31 == 7 (mod 8),
q == 5 (mod 8),
```

the condition `d in {1,q}` in `Q_2*/Q_2*2` is precisely

```text
e = 0,
s = f.                                                         (3.3)
```

The four solutions of (3.3) are

```text
1, q, -31, -31*q.
```

They are not merely everywhere locally soluble: they are the global Kummer
images of

```text
O, (q,0), (0,0), (-31*q,0) in E'_q(Q),
```

respectively. Therefore

```text
Sel^(phi_q)(E_q/Q) = {1,-31,q,-31*q}.                          (3.4)
```

## 4. The dual local images

Here the Kummer map is the `x`-coordinate map on

```text
E_q: y^2 = x*g_q(x),
g_q(x) = x^2 - 15*q*x + 64*q^2.                               (4.1)
```

The special point `(0,0)` maps to `64*q^2`, which is a square, so it adds no
nontrivial class.

### 4.1 Infinity

The discriminant of `g_q` is

```text
(-15*q)^2 - 4*64*q^2 = -31*q^2 < 0.
```

Thus `g_q(x)>0` for every real `x`. A nonzero real point in (4.1) must have
`x>0`. Conversely the identity supplies the positive class. Hence

```text
im(alpha_dual,infinity) = {positive squareclass}.              (4.2)
```

### 4.2 The prime 2

**Lemma 4.2.** If `q == 5 (mod 8)`, then

```text
im(alpha_dual,2) = {d in Q_2*/Q_2*2 : v_2(d)=0};
```

that is, all four unit squareclasses and no class of odd valuation.

**Proof, exclusion.** Let `(x,y)` be a nonzero point and put `k=v_2(x)`.
If `k<0`, the `x^2` term uniquely determines `v_2(g_q(x))=2k`, so
`v_2(y^2)=3k`; an odd `k` is impossible. If `k>6`, the constant term
uniquely gives `v_2(g_q(x))=6`, and again an odd `k` is impossible.

It remains to exclude `k=1,3,5`. Write `x=2^k*xi` with `xi` odd and divide
`y^2=x^3-15*q*x^2+64*q^2*x` by `2^(2k)`. The resulting odd unit is

```text
U_k = 2^k*xi^3 - 15*q*xi^2 + 2^(6-k)*q^2*xi.                  (4.3)
```

Since `q==5 (mod 8)` and `xi^2==1 (mod 8)`, (4.3) is congruent modulo 8 to

```text
k=1:  5 + 2*xi, which is 3 or 7;
k=3:  5;
k=5:  5 + 2*xi, which is 3 or 7.
```

None is a 2-adic square unit. Therefore every Kummer `x`-class has even
2-adic valuation.

**Proof, realization of all unit classes.** Since `q/5 == 1 (mod 8)`, choose
`s in Q_2*` with `q=5*s^2`. The substitution

```text
x=s^2*X, y=s^3*Y
```

identifies `E_q/Q_2` with

```text
E_5: Y^2 = X^3 - 75*X^2 + 1600*X
```

without changing the squareclass of the `x`-coordinate. On `E_5`, the
following `X` values realize the three nontrivial unit classes:

```text
X=12 (class 3):  Y^2 = 10128 = 16*633,  633 == 1 (mod 8);
X=20 (class 5):  Y^2 = 10000 = 100^2;
X=28 (class 7):  Y^2 =  7952 = 16*497,  497 == 1 (mod 8).
```

An odd 2-adic unit is a square exactly when it is `1 (mod 8)`, so all three
points exist over `Q_2`. The identity gives class 1. QED

### 4.3 The prime 31

**Lemma 4.3.** Under `(q/31)=-1`,

```text
im(alpha_dual,31) = {1}.
```

**Proof.** Modulo 31,

```text
g_q(x) == (x-r)^2,
r = (15/2)*q == 23*q            (mod 31).                     (4.4)
```

Moreover `r` is a square modulo 31. Indeed,

```text
(23/31) = -(31/23) = -(8/23) = -1,
```

while `(q/31)=-1`, so `(r/31)=+1`.

Let `(x,y)` be a point with `x!=0`, and put `k=v_31(x)`.

* If `k<0`, then `g_q(x)/x^2` is `1 (mod 31)`, hence is a square. The
  equation forces `x` to be a square.
* If `k>0`, then `g_q(x)/(8*q)^2` is `1 (mod 31)`, hence is a square. Again
  `x` is a square.
* If `k=0` and `x` does not reduce to `r`, (4.4) is a nonzero square, so
  `g_q(x)` and then `x` are squares.
* If `k=0` and `x` reduces to `r`, the residue of `x` is itself a nonzero
  square, so `x` is a square.

The special class at `(0,0)` is also square. Thus only class 1 occurs, and it
does occur. QED

### 4.4 The prime `q`

**Lemma 4.4.** Under (3.2),

```text
im(alpha_dual,q) = {1}.
```

**Proof.** Let `k=v_q(x)` for a nonzero point.

* If `k<=0`, then `g_q(x)/x^2` is `1 (mod q)`, hence square; the equation
  forces `x` to be square.
* If `k>1`, then `g_q(x)/(8*q)^2` is `1 (mod q)`, hence square; again `x`
  is square.
* If `k=1`, write `x=q*xi`. Then

  ```text
  g_q(x) = q^2*(xi^2 - 15*xi + 64).
  ```

  The polynomial in parentheses has discriminant `-31`, a nonsquare
  modulo `q` by (3.2). It has no root modulo `q`, so `v_q(g_q(x))=2` and
  `v_q(x*g_q(x))=3`, impossible for a square.

Thus every local Kummer class is square, and class 1 occurs. QED

### 4.5 Global intersection for the dual

For the bit representation (2.2), the exact local conditions are

```text
infinity:  s = 0;
2:         e = 0;
31:        f = 0 and s = g;
q:         g = 0 and e = f.                                  (4.5)
```

The formulas at 31 use

```text
(-1/31)=-1, (2/31)=+1, (q/31)=-1,
```

and those at `q` use

```text
(-1/q)=+1, (2/q)=-1, (31/q)=-1.
```

Their unique common solution is

```text
s=e=f=g=0.
```

Therefore

```text
Sel^(hat_phi_q)(E'_q/Q) = {1}.                                (4.6)
```

Notice that the real, 2-adic, and 31-adic conditions already have trivial
global intersection. Lemma 4.4 is nevertheless included because the frozen
project explicitly requires the twisting-prime local image.

prime family determined only by positivity, `q==5 (mod 8)`, and
