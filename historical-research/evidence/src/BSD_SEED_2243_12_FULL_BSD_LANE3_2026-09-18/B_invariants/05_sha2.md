## 5.1 The exact sequences used (2-isogeny descent)

Let ψ: E → E′ be the 2-isogeny with kernel ⟨T⟩, T = (0,0), and ψ̂: E′ → E its dual, so ψ̂∘ψ = [2].
- E′ = E/⟨T⟩: y² = x³ + 10A x² + 9mA x = [0, 45470, 0, 91790289, 0]. Its minimal model is [0, −1, 0, −597383344, 5572681004764]
  (mwrank; see B.7).
- mwrank's names: its "φ′" is ψ (E → E′) and its "φ" is ψ̂ (E′ → E). So mwrank's S^{φ′}(E) = Sel^ψ(E) ⊇ E′(Q)/ψE(Q), and
  S^{φ}(E′) = Sel^ψ̂(E′) ⊇ E(Q)/ψ̂E′(Q). This is confirmed by its printed "E(Q)/phi(E'(Q))" and "#III(E/Q)[phi']".

Standard facts (Silverman, AEC X.4.2 and X.6; Cremona, *Algorithms*, §3.6):
1. 0 → E′(Q)/ψE(Q) → Sel^ψ(E/Q) → Sha(E/Q)[ψ] → 0, and likewise for ψ̂ on E′. Here Sha(E)[ψ] := ker(ψ_*: Sha(E) → Sha(E′)).
2. 0 → E′(Q)[ψ̂]/ψ(E(Q)[2]) → E′(Q)/ψE(Q) → E(Q)/2E(Q) → E(Q)/ψ̂E′(Q) → 0 (the middle map is induced by ψ̂). With E(Q)[2] = ⟨T⟩
   (B.2) we have ψ(E(Q)[2]) = 0, and E′(Q)[ψ̂] = ⟨T′⟩ has order 2. Since #E(Q)/2E(Q) = 2^{r+1}, this gives
   **r = dim E(Q)/ψ̂E′(Q) + dim E′(Q)/ψE(Q) − 2 ≤ dim Sel^ψ̂(E′) + dim Sel^ψ(E) − 2.**
3. 0 → Sha(E)[ψ] → Sha(E)[2] → Sha(E′)[ψ̂] (the second map is ψ_*): if x ∈ Sha(E)[2] then ψ̂(ψ(x)) = 2x = 0, and ker ψ_* = Sha(E)[ψ].
4. 0 → E(Q)/2E(Q) → Sel₂(E/Q) → Sha(E/Q)[2] → 0.

## 5.3 Proof of Sha(E/Q)[2] = 0 and dim Sel₂ = 3

- By 5.2 (mwrank and Miller, independently), dim Sel^ψ(E) = dim Sel^ψ̂(E′) = 2. By 5.1(2), r ≤ 2 + 2 − 2 = 2.
- By B.4, r ≥ 2 (P₁ and P₂ independent). So r = 2 and equality holds in 5.1(2). That forces E′(Q)/ψE(Q) = Sel^ψ(E) and
  E(Q)/ψ̂E′(Q) = Sel^ψ̂(E′). By 5.1(1), **Sha(E)[ψ] = 0 and Sha(E′)[ψ̂] = 0**.
- By 5.1(3), **Sha(E/Q)[2] = 0**. By 5.1(4), dim Sel₂(E) = dim E(Q)/2E(Q) = r + 1 = **3**. PARI's full 2-descent (C = 3) and mwrank's
  second descent (rk S²(E) = 3) confirm this independently.
- **Sha(E/Q)[2^∞] = 0**: a 2-primary torsion group with no element of order 2 is trivial.

By the symmetric sequence 0 → Sha(E′)[ψ̂] → Sha(E′)[2] → Sha(E)[ψ], also **Sha(E′/Q)[2] = 0**, hence **Sha(E′/Q)[2^∞] = 0**. This is
used in B.7.
