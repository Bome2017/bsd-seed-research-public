## 3. Theorem 1.7 degenerates for this seed — decisive, and it is the recorded rank-two obstruction

The Heegner hypothesis in Theorem 1.7 requires every prime divisor of the conductor to split in `K`. Under that
hypothesis the root number of `E/K` is `-1`, so

    ord_{s=1} L(E/K, s)  is odd.

For the seed, `ord_{s=1} L(E/Q, s) = 2` (rigorous, `PROVED_COMPUTER_ASSISTED`). Since
`L(E/K,s) = L(E/Q,s) · L(E^K/Q,s)`,

    ord L(E/K, s) = 2 + ord L(E^K, s),   which is odd  =>  ord L(E^K, s) is odd >= 1  =>  ord L(E/K, s) >= 3.

By Gross-Zagier, `hhat_K(y_K) = c · L'(E/K, 1)`, and `ord >= 3 > 1` forces `L'(E/K,1) = 0`. **Hence the Heegner point
`y_K` is torsion, for every `K` satisfying the Heegner hypothesis.** The Heegner-point Stark system `ε^Hg` is then built
from a torsion class, the Heegner point main conjecture degenerates, and the Fitting-ideal identity carries no bound.

This is not a repairable detail. It is forced by the seed's **even** analytic rank 2 together with the Heegner
hypothesis, and it is precisely the obstruction already on record: primitive analytic rank two makes first-derivative
Heegner/Kolyvagin machinery vanish at the relevant interface (`DO_NOT_RESURRECT.md`; killed-routes §7 of the invention
packet). Theorem 1.7 is a Heegner-point construction and inherits it.

Two independent applicability failures remain even setting that aside:

* **Ordinary only.** Theorem 1.7 assumes good ordinary reduction at `p`. The seed's obligation covers ordinary,
