## How to formulate the invention work from our actual mathematics

There are two distinct obligations. One theorem could eventually settle both, but that is not established and is not a requirement imposed on every candidate.

### A. Preferred initial design problem: real comparison

The available objects are the actual divisors [P_i]-[O], their global canonical height pairing, the modular parametrization, and the explicit Mellin/RS2 analytic expressions. Begin from these objects, not from a scalar defined to equal the desired answer.

The first research product should be a **specified arithmetic construction with one independently calculable realization**, followed by one comparison lemma to attempt. For example, an arithmetic correspondence or intersection would need a defined cycle/divisor, a model and finite-place corrections, and a proof that its arithmetic pairing involves both P1 and P2. Calling an object a higher height or regulator is not that construction.

For any proposed correspondence using the existing analytic bridge, the first test is its exact realization: compute the relevant pullback, pushforward, or regulator kernel and compare it with the recorded kernel, including every residual and boundary term. Check equality of functions/distributions or a proved pairing identity; resemblance of special functions is insufficient. Do not start by repairing RS2's analytic continuation in isolation. That repair becomes useful only if an independently specified arithmetic side makes it load-bearing.

The following are immediate tests generated by existing facts:

1. The retained regulator certificate includes finite-place terms. A smooth function of the complex point alone cannot recover the global canonical height; the existing working proof uses compactness against quadratic growth on multiples of a point. An arithmetic model or a justified nonlocal construction must account for that information.
2. For Q_i = sum_j A_ij P_j, the regulator changes by det(A)^2. A proposed two-point construction must reproduce this covariance, with an explicit index normalization for a nonsaturated pair. This is a test, not a new determinant-line construction.
3. Both tested automorphic vertex completions have nonzero residuals. An exact comparison must retain or independently explain them. They cannot be deleted by convention.
4. The full-domain scalar-curvature theorem also covers scalar two-variable kernels under its hypotheses. Merely adding another variable does not evade Stokes. A candidate must identify the actual changed hypothesis, such as a proved nonexact arithmetic cycle; no such cycle is asserted here.
5. A p-adic height identity alone cannot supply the real comparison. Finite digits and unit statements do not control a characteristic-zero scalar or its conjugates.

The complete intended implication is:

    independent construction and both exact comparisons
      -> M2 = explicit constant * Omega * R
      -> evaluate the constant in the retained normalization
      -> q = 36, if that evaluated constant is 36.

Equivalently a comparison stated for L'' must produce 72. These numbers are endpoint checks, never coefficients chosen to define the construction. Quantitative arithmeticity with the already recorded denominator/conjugate bounds is another acceptable terminal implication, but it has no demonstrated difficulty advantage.

**First unproved arrow:** identifying an arithmetic realization of the analytic object with a proved global two-point height comparison. No inspected source or existing file supplies it. A candidate with that missing arrow merely assumed has not passed admission. This plan does not claim that a specific new construction has already passed the gate.

**What remains after success:** order nine for Sha. This lane alone does not prove FIN or full BSD.

### B. Separate invention requirement: control all excess Selmer classes

Use the exact sequence as a test of any proposed construction:

    0 -> E(Q)/p^n E(Q) -> Sel_(p^n)(E/Q) -> Sha(E/Q)[p^n] -> 0.

The known points account for the first term. What must be bounded is the quotient, including its integral torsion. Rational Selmer dimensions cannot see finite primary Sha: at 3 that rational dimension is already two while the retained primary group has order nine. At 5,7,11 the quotient vanishes. These are existing positive and zero controls for a new invariant; recomputing them is not a new research goal.

If the source application exposes an independent integral quantity, attempt a comparison between that quantity and this quotient before numerical exploration. A fixed nonzero integer with a proved Sha-support implication could give finite support, but still needs primary finiteness/depth control at its divisors and exact remaining orders. A bounded source surjecting onto the quotient and a bounded target receiving it injectively are both admissible.

An alternative is a direct whole-group size argument. It need not partition primes. Under the retained inputs a proved finite order below 1521 forces order nine; naming that bound is not evidence that it is easier to prove. A uniform bound on all Sha[n] can also imply global finiteness, but establishing that bound is the arithmetic work.

**First unproved arrow:** an independently proved global bound on the quotient, not merely a new presentation of it. A matrix using only localizations of P1,P2 has not captured arbitrary Sha classes. A fixed perfect complex or source lattice does not by itself bound all evaluated defects. Any prime-wise strategy must cover ordinary, supersingular, bad primes, and all primary depths.

**What remains after success:** q=36 unless the same construction also proves the real comparison. Proving FIN alone still leaves order nine open.
