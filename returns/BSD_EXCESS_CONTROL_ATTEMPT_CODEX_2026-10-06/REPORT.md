# Independent excess-control attempt and two Aristotle projects

Date: October 6, 2026, Pacific.

**NO_INDEPENDENT_BOUND_CONSTRUCTED; ARISTOTLE_PACKAGES_PREPARED_NOT_SUBMITTED.**

The task was to attempt arithmetic control of
Sha[p] = C[t]/t^2 C, and prepare Aristotle packages if that could not be
constructed. I tested a source beyond the existing deformation argument
and checked a fixed-object candidate against the actual prior returns.
Neither supplied the bound. I then built two different research projects
with the complete original reading set and the subsequent evidence overlay.

## Mathematical work in this pass

The recently published higher-anticyclotomic-Fitting paper had been listed
in the archive at title-level only. I read its ordinary hypotheses,
Fitting statements and the specialization/auxiliary-prime arguments. The
attempted use was a specialization giving an independent annihilator of
the original excess. It did not produce a controlled augmentation unit.
The exact missing inference, source locators and scope are recorded in
[LOCAL_ATTEMPT.md](LOCAL_ATTEMPT.md). No claim that all the paper's seed
hypotheses have been verified is made.

An explicit abstract module calculation isolates why the coarse Iwasawa
properties cannot fill that step. Over R=Z_p[[T]],

    Y_e = R + (R/(T))^2 + (R/(T+p))^(2e)

has rank one, exactly doubled torsion, mu=0 and no finite submodule, but

    Y_e/T Y_e = Z_p^3 + F_p^(2e).

This is a short written algebra control, not a seed Selmer realization,
new arithmetic bound, literature novelty claim, or proof that a more
substantial specialization estimate is impossible.

The fixed 1-motive [Z^2 -> E] was also considered. Its two previous
Aristotle runs and review already test the relevant determinant/local-data
construction and leave the arithmetic generator unresolved. I found no
new generator, so did not rerun that work. The packages explain precisely
what would have to change to reopen it.

## What Aristotle is now asked to construct

**A — direct excess control.** An actual map to an independently bounded
arithmetic target, an arithmetic rank estimate, or a proved unit annihilator.
The task allows p-dependent arithmetic and does not make a fixed scalar
mandatory. Its Fitting/specialization entry point requires actual arithmetic
information beyond the dictionary screened above.

**B — fixed global support.** A fixed arithmetic object with actual integral
realization maps and a proved rank/support bound. One sufficient construction
is a fixed finitely generated abelian group G of rank at most one and
injections Sha[p] -> G/pG outside a fixed finite set; another is an
independently constructed fixed nonzero annihilator. These are requested
constructions, not claims that such objects are already available.

Both tasks distinguish proving an equivalent criterion by independent
arithmetic from merely restating it. They forbid silently inserting Sha,
q, ETNC, a wild regulator unit or uncontrolled p-dependent scalars. They
also prohibit spending the job on another lifting order or another fixed-p
campaign. A useful partial must construct new arithmetic control and state
the exact remaining step. An unsuccessful search stays explicitly scoped
to its tested candidates.
