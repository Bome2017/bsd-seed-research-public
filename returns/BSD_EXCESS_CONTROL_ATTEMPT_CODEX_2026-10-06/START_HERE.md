## Use with Aristotle

Unzip the selected package. Its outer folder contains `project/`.
Submit that **project directory** with the prompt in
`project/SUBMISSION_PROMPT.txt`. The exact command is recorded in
`project/SUBMIT_COMMAND.txt`. If uploading the whole outer folder, tell
Aristotle to work inside `project/`, as in the successful earlier run.

The request is to construct new arithmetic, not to formalize a completed
BSD proof. `project/TASK.md` governs. The first operation is
`python3 prepare_reference.py`, which extracts both the original reading
set and current overlay, checks their manifests, and prints the roots.

Harmonic's real aristotlelib 2.1.0 project packer was exercised with the
network transport replaced by a local capture. Both payloads fit its
104,857,600-byte limit, include all 29 submitted files, and locally extract
and recheck all 6,566 bound reference entries. No real project was created.
This is preparation evidence, not a claim that the server has accepted
these new packages or that it will solve the arithmetic problem.
