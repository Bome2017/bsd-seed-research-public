# Coinvariant / norm descent of the receiver B_p

**Status: NO_NEW_BOUND_FROM_COINVARIANTS.**

What this file proves:

* the exact relation between `B_p` and the `P_p`-coinvariants (Theorem 1);
* the actual norm / Tate-cohomology sequence for `(A_p)_{P_p}` (Theorem 2);
* the new arithmetic computations of its `V`-parts (Theorem 3). These include a descent of `B_p`
  to the `S`-class group of `K'_p`, with a defect window of one, proved without the receiver
  exactness theorem.

The precise fact that ends the route is Theorem 4. The descended receiver is, by
inflation–restriction alone, the strict-at-`p` Selmer group of `E/Q`. So the coinvariant
mechanism reconstructs `Sha[p]` and gives no independent multiplicity bound. This conclusion
concerns **only** the norm/coinvariant mechanism. It says nothing about other class-group
methods, which are neither excluded nor assessed here.

The receiver exactness theorem (CORRECTED_PROOF.md, HANDOFF.md) is taken as fixed. It is not
reproved, and it is never used as a bound. `p = 4547` is not revisited: every statement below
assumes `p ≥ 5` and `p ≠ 4547`. Theorems 1 and 2 hold verbatim at 4547 as well, but the
`V`-part computations of Theorem 3 need the local inputs listed in §0, and those are retained
only for `p ≠ 4547`. Nothing below uses `dim Sel_p = 2`, `Sha[p] = 0`, or BSD.

Notation: `K = K'_p`, `L = L_p`, `P = P_p = Gal(L/K)`, `G0 = G_{0,p} = Gal(K/Q)`, `V = E[p]`.
`S` is the set of places of `K` above `p` (and above ∞; `K` is totally complex). `Cl_S` is the
class group with the primes above `p` inverted, and `A = A_p = Cl_S(L)/p`.

## 0. Inputs used (all retained/reviewed or standard)

* (R1) `G0 = GL2(F_p) × C2`, `P ≅ V ⊕ V ⊕ U` with `U ∈ {0, Vε}` (semisimple). The first two
  coordinates are the Kummer maps of `P1, P2`. `z = (−I, 1)` is central and acts by `−1` on `V`
  and on `P`.
* (R2) `H¹(G0, V) = H²(G0, V) = 0`; `H¹(G0, End V) = 0`; `H¹(G0, Hom(Vε, V)) = 0`
  (UPPER_CONTROL §2, Lemma 2.3, reviewed). Equivalently `Ext¹_{G0}(V, V) = Ext¹_{G0}(Vε, V) = 0`.
* (R3) `L/K` is unramified outside `S`: the Kummer classes have `p`-unit Tamagawa factors
  (CORRECTIONS C2).
* (R4) Local facts at a place `w | p` of `K` (CORRECTED_PROOF §5, `p ≠ 4547`):
  * `p` splits in `F_p`, so `K_w = Q_p(E[p])`;
  * with `G_w = Gal(K_w/Q_p) ⊂ G0`, `H¹(G_w, V) = 0`;
  * `L_w = K_w(Q3)`;
  * the translation subgroup `T_w = {σQ3 − Q3}` is the `χ1`-line (ordinary or multiplicative
    reduction) or all of `V` (supersingular reduction);
  * in both cases `dim Hom_{G_w}(T_w, V) = 1`.
* (R5) `ℓ_p := Hom_{G0}(P/D_S, V) = {(a, b) : aP1 + bP2 ∈ pE(Q_p)}`, with `dim ℓ_p = 2 − λ_p`,
  where `λ_p := dim loc_p(W) ∈ {0, 1}` and `W = E(Q)/p` (UPPER_CONTROL §7.3). Here `D_S ⊂ P` is
  the subgroup generated by the decomposition groups `D_w` for `w | p`.
* Standard results: class field theory (global and local reciprocity, the Artin map and norm
  compatibility), Tate's description of the knot group, Tate–Nakayama, Frobenius reciprocity,
  and inflation–restriction.

## 1. Theorem 1 (coinvariant identification) — formal core in Lean

Let `I_P A` be the span of the elements `σa − a` for `σ ∈ P`, and put `A_P = A/I_P A`. Then
`Γ` acts on `A_P` through `G0 = Γ/P`, and composition with `A → A_P` is a canonical
`F_p`-linear isomorphism

    Hom_{G0}((A_p)_{P_p}, V)  ≅  Hom_{Γ_p}(A_p, V) = B_p.

It is an equality: there is no kernel, no cokernel, and no Ext correction. *Proof.* A
`Γ`-map `f` satisfies `f(σa − a) = σf(a) − f(a) = 0` for `σ ∈ P`, because `P` acts trivially on
`V`. So `f` factors through `A_P`. `I_P A` is `Γ`-stable because `P` is normal, and `P` acts
trivially on `A_P`. ∎

Lean (`Coinvariant/Descent.lean`, no `sorry`, only standard axioms):

* `CoinvariantDescent.homEquivCoinvQuot` gives the isomorphism for an arbitrary group `Γ`, normal
  subgroup `P`, and commutative coefficient ring;
* `coinvRep_trivial` shows that `P` acts trivially on `A_P`;
* `equivHom_quot_eq` shows that `Γ`- and `Γ/P`-equivariance agree.

Since `(−)_P` is right exact and `A_P = Cl_S(L)_P / p`, all later work is about `Cl_S(L)_P`.

## 2. Theorem 2 (the norm / Tate-cohomology sequence for `Cl_S(L)_P`)

Let `N̄ : Cl_S(L)_P → Cl_S(K)` be the norm. It is `G0`-equivariant. Write:

* `𝔎 := ker N̄`;
* `K^×_{(S)}` for the set of elements of `K^×` that are local norms from `L` at every place
  `v ∉ S`;
* `ρ_S : O_{K,S}^× → X := ⊕_{w|p} D_w` for the local Artin symbols, with
  `Σ : X → P` the sum map.

Then the following sequences are exact and `G0`-equivariant.

(2a) Norm (genus) sequence:

    0 → 𝔎 → Cl_S(L)_P →N̄ Cl_S(K) → P/D_S → 0.

The cokernel is `Gal(L ∩ H_S(K)/K) = P/D_S` by CFT and (R3).

(2b) Kernel as a norm-residue group:

    𝔎 ≅ K^×_{(S)} / (N L^× · O_{K,S}^×).

*Proof.* `L/K` is unramified outside `S`, so `(I_{L,S})_P = ⊕_{v∉S} Z`, and the norm
multiplies the `v`-coordinate by `f_v`. Hence the norm is injective on `(I_{L,S})_P`. A diagram
chase gives `𝔎 ≅ (N I_{L,S} ∩ Pr_{K,S}) / N Pr_{L,S}`. For unramified `v`, an element is a local
norm if and only if its valuation is divisible by `f_v`. ∎

(2c) Tate / knot filtration:

    0 → (O_{K,S}^× ∩ N J_L)/(O_{K,S}^× ∩ N L^×) → Kn(L/K) → 𝔎 → ker Σ / ρ_S(O_{K,S}^×) → 0,

The knot group is

    Kn(L/K) = (K^× ∩ N J_L)/N L^× ≅ Ĥ^{-3}(P, Z) / Σ_v cor Ĥ^{-3}(D_v, Z) = Λ²P / Σ_{w|p} Λ²D_w.

This is Tate's theorem with `Ĥ^{-3}(P, Z) = H_2(P, Z) = Λ²P` (`P` is elementary abelian).
Unramified decomposition groups are cyclic and contribute nothing. The right-hand term comes from
`K^×_{(S)}/NL^× → ⊕_{w|p} K_w^×/N L_w^× = X`. Its image is exactly `ker Σ`, by global
reciprocity together with the idelic description of `K^× ∩ N J_L`. The Tate–Nakayama
isomorphism is cup product with the `Γ`-invariant fundamental class, so it is
`G0`-equivariant.

So `(A_p)_P` is controlled by four pieces:

* the `S`-class group of `K'_p`;
* the decomposition groups `D_w` above `p` (through `P/D_S` and `ker Σ`);
* `S`-units (through `ρ_S`);
* `Λ²P` (the knot group).

Ramification outside `S` is absent by (R3).

## 3. Theorem 3 (V-parts of the pieces) — new computations, independent of receiver exactness

Write `h_p := dim Hom_{G0}(Cl_S(K'_p)/p, V)`, the `V`-multiplicity of the head of the
`S`-class group of the **lower-degree** field `K'_p`, of degree `2|GL2(F_p)|`. The field `L_p`
has degree larger by the factor `|P| = p⁴` or `p⁶`.

(3a) **Knot part contributes no V.** `Hom_{G0}(Λ²P/…, V) = 0`, because `z` acts by `+1` on
`Λ²P` and by `−1` on `V` (Lean: `equivHom_eq_bot_of_sign`). Hence

    Hom_{G0}(𝔎/p, V) = Hom_{G0}(ker Σ / ρ_S(O_{K,S}^×), V) ⊂ Hom_{G0}(ker Σ, V).

(3b) **Decomposition/S-unit part: explicit bound** `dim Hom_{G0}(𝔎/p, V) ≤ 1 − λ_p`.

* `X ≅ Ind_{G_w}^{G0} D_w`, and `D_w ≅ T_w` equivariantly because `L_w = K_w(Q3)`. By Frobenius
  reciprocity and (R4), `dim Hom_{G0}(X, V) = dim Hom_{G_w}(T_w, V) = 1`.
* `D_S = Σ(X) ⊂ P` is semisimple, `D_S ≅ V^{a} ⊕ U^{b}`. By (R2), `Ext¹_{G0}(D_S, V) = 0`.
  Therefore `0 → ker Σ → X → D_S → 0` gives `dim Hom_{G0}(ker Σ, V) = 1 − a`.
* `P/D_S ≅ V^{2−a} ⊕ …`, so (R5) gives `a = λ_p`.

(3c) **Image of the norm.** Put `J = ker(Cl_S(K)/p → P/D_S)`. Then:

* `Hom_{G0}(J, V) = Hom_{G0}(Cl_S(K)/p, V)/ℓ_p`. Surjectivity holds because
  `Ext¹_{G0}(P/D_S, V) = 0` by (R2).
* The kernel `I''` of `N̄(Cl_S(L))/p → J` is a `G0`-quotient of
  `Tor_1(P/D_S, Z/p) = P/D_S`, so `Hom_{G0}(I'', V) ↪ ℓ_p`.

(3d) **Descent window (new; no receiver exactness).** Steps (3a)–(3c) and Theorem 1 combine to
give

    h_p − 2 + λ_p  ≤  dim B_p  ≤  h_p + 1 − λ_p.

The left inequality is the injectivity of `N^* : Hom_{G0}(Cl_S(K)/p, V)/ℓ_p ↪ B_p`, which was
already in UPPER_CONTROL (7.1). The right inequality is new: it is an upper bound on the receiver
by the `V`-multiplicity of a lower-degree arithmetic module. In the generic case `λ_p = 1`,
meaning `W ⊄ pE(Q_p)`, it reads `h_p − 1 ≤ dim B_p ≤ h_p`.

## 4. Theorem 4 (precise reconstruction of Sha[p]) — why this gives no new bound

(4a) **The descended receiver is a Selmer group of E/Q (unconditional).** By (R2),
inflation–restriction gives `H¹(Q, V) ≅ H¹(K, V)^{G0}`. Under this isomorphism, the
`G0`-homomorphisms `Cl_S(K)/p → V` (unramified everywhere and split at `w | p`, by CFT)
correspond to

    S_p^str := { c ∈ H¹(Q, V) : loc_q c ∈ ℒ_q for q ≠ p,  loc_p c = 0 }.

The local conditions match as follows:

* At `q ≠ p`, `I_{K,w} = I_{L,w}` by (R3), so the `K`-level condition is the pulled-back
  condition `ℒ_q`.
* At `p`, the condition is `H¹(G_w, V) = 0` by (R4).

Hence `h_p = dim S_p^str`.

(4b) **The norm pullback is restriction.** Artin reciprocity gives `χ∘N = χ∘res`. So
`N^* : S_p^str → S_p/W ≅ B_p` has

    kernel = S_p^str ∩ W = ℓ_p,     cokernel ≅ loc_p(S_p)/loc_p(W).

The Lean statements are `strict_to_quot_ker` and `strict_coker_equiv`; `strict_surj_of_loc_eq`
covers the surjective case.

(4c) **Combined with the fixed theorem** (`S_p = Sel_p` for `p ≠ 4547`, used here only as an
identification), `S_p^str = Sel_p^str`, and

    0 → ℓ_p → Hom_{G0}(Cl_S(K'_p)/p, V) → Sha[p] → loc_p(Sel_p)/loc_p(W) → 0.

If `λ_p = 1`, then `B_p ≅ Hom_{G0}(Cl_S(K'_p)/p, V)/ℓ_p` exactly, and `h_p = dim Sha[p] + 1`.

So the norm/coinvariant mechanism transports `B_p` down to `K'_p`, and the receiver there is
exactly the strict Selmer group of `E/Q`. Any bound on `h_p` is literally a bound on
`Sel_p^str`, and hence on `Sha[p]`. The non-class-group terms are killed outright: the knot
part (3a) and, when `λ_p = 1`, the decomposition/`S`-unit part (3b). They cannot supply an
independent constraint. **NO_NEW_BOUND_FROM_COINVARIANTS.**
