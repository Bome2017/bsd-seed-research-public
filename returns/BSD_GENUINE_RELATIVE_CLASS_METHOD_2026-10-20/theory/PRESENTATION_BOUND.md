# A sufficient relative presentation for an upper bound

Date: 2026-10-20. Written elementary deduction, not a completed seed class
calculation. The seed's field, maximal order, scalar action, and preceding
unit/class source sequence are retained inputs.

## 1. The arithmetic group that must be covered

Let A be the actual degree-24 nonzero-5-torsion point field and let
K=A^{<tau>}, where tau is the scalar -1. Thus [K:Q]=12 and [A:K]=2.
Let sigma be the scalar 2, so sigma has order four and sigma^2=tau.
For chi(sigma)=2 or 3 in F_5^*, write

    C_chi = (Cl(A)/5 Cl(A))^chi.

The dimensions of this group and Cl(A)[5]^chi agree; this does not assert
a canonical isomorphism between these two groups. Character projectors are
exact because four is invertible modulo five.

Write j for extension of ideals and N for norm. On class groups,
Nj=2 and jN=1+tau. Consequently the five-primary class group splits into
the image of j and the anti-invariant norm kernel. Both faithful characters
lie in that kernel. In particular, either faithful component of
Cl(A)/j Cl(K) is precisely the required component of Cl(A), not an estimate
obtained from the smaller field. A base ideal class can be discarded only
after this authenticated odd-character projection.

## 2. What a partial relative calculation proves

Choose a finite scalar-stable list of actual prime ideals of A. Project the
free divisor space on this list to chi, choose a basis, and denote its
dimension by m. Ideal multiplication gives a well-defined linear map

    v : F_5^m -> C_chi.

Let R be a subspace of ker(v) generated by authenticated relation rows,
and let r_C=dim R. Define the omitted-generator defect

    Q_gen = coker(v),    q=dim Q_gen.

Then

    dim C_chi <= m-r_C+q.                         (1)

Proof: v induces a surjection F_5^m/R -> im(v). Its domain has dimension
m-r_C. The exact sequence 0 -> im(v) -> C_chi -> Q_gen -> 0 proves (1).

This is an upper-bound certificate. A complete relation lattice, a class
number, and saturation of all relations are NOT required. Missing relations
only make m-r_C an overestimate. Missing generators are different: q must
be bounded or proved zero before (1) is numerical. In particular, a finite
quotient computed from the selected generators does not control q.

An abstract diagnostic makes this sharp. The same selected-generator
presentation maps to its image in C_chi direct-summed with F_5^e for every
e>=0. All its relation checks remain unchanged, while the omitted defect
increases by e. This is not a seed example or an impossibility theorem; it
identifies the exact extra assertion a certification must establish.

## 3. Relative relations that are acceptable

An exact fractional-ideal identity

    product_j P_j^{a_j} = (alpha) j(b)

with alpha in A^* and a fractional ideal b of K gives a valid chi relation.
The base ideal b need not be principal: its faithful projection is zero.
More generally the right-hand side may include J^5 for an authenticated
fractional ideal J of A. This still gives a relation in C_chi. Every ideal,
automorphism, and equality must be checked in the same maximal order.

If a proposed relation contains a private residual ideal J not known to
be a fifth power modulo the selected span, it is not a closed relation.
Keep J as a new column, or keep its contribution in Q_gen. Omitting that
column while keeping the row can create a false upper bound.

Equivalent anti-invariant witnesses can be checked without principalizing
any base ideal. For I=(alpha)j(b)J, application of tau gives

    I/tau(I) = (alpha/tau(alpha)) J/tau(J).        (2)

The eigenvalue of tau on the faithful component is -1, and 2 is a unit
modulo five. Thus replacing an ideal by its anti-invariant quotient does
not lose that component. Equation (2) remains an identity about actual
ideals, not about normed coefficients alone.

## 4. A sufficient generation-modulo-five gate

It suffices to certify q=0. It is not necessary to compute all of Cl(A).
One unconditional route is a proved class-group prime-generation bound B,
followed by exact coverage of every relevant prime orbit with norm <=B.
For each such orbit, give an identity showing that its chi projection lies
in the selected span modulo 5: selected ideals times a fifth-power ideal,
a principal ideal, and an extended base ideal suffice. The relation must
include a witness for every term.

Prime orbits whose scalar stabilizer is nontrivial under chi contribute
zero and need no column. In particular, primes fixed by tau are invisible
in the faithful component. This removes inert and ramified prime ideals
of A/K from that component, but not the split pairs. These exclusions must
use the actual scalar action, not only a residue-degree guess.

For chi(sigma)=2, an integral representative of the projector modulo five
has weights (4,2,1,3) on (1,sigma,sigma^2,sigma^3). Thus these tests can be
written with ordinary ideal products. The analogous weights for chi=3
are (4,3,1,2). These are modulo-five projectors; their use does not claim
that a chosen integer lift is an idempotent over Z.

Any independently proved smaller generation theorem can replace the
Minkowski coverage. A GRH generation bound, without independent removal
of its hypothesis, certifies only a conditional q=0.

## 5. Joint unit and ordinary-class budget

Let U_chi be the faithful unit space in A^*/A^{*5}. Its full dimension is
the retained d=3 at the seed's coefficient five. More generally the
full-image point-field calculation gives d=(p+1)/2. Suppose actual units
and exact norm/local evaluations certify rank r_U on that unit space.
This is a lower rank bound: neither a full unit basis nor a unit regulator
is required. Independence must hold modulo p-th powers, not just in the
real logarithmic lattice.

On the retained domain where the faithful valuation term is zero, the
unit/class source sequence therefore gives the conservative complete bound

    dim K_chi <= d-r_U + m-r_C+q.                 (3)

The right-hand class term bounds the entire ordinary class component;
it does not assume that the companion class norm is injective. Using an
authenticated class-norm kernel can improve (3), but is not necessary for
this sufficient test. If a valuation term survives, add its independently
proved bound rather than silently omitting it.

At p=5, generation modulo five and r_U-(m-r_C)>=1 give bound at most two.
Across primes, the same target is

    r_U-(m-r_C) >= (p-3)/2,   with q=0.          (4)

Equation (4) states the required measured rank profile. It is not proved
for the seed or across primes by this note. Passing a complete p=5 source
bound would test this construction on the actual seed; it would not by
itself constitute a cofinite FIN theorem.

## 6. Status

The useful relaxation is exact: authenticated relations plus generation
modulo p can give an upper bound without full class/unit computation.
This note supplies that certificate interface and its proof. It does not
certify generator completeness, evaluate a new seed class bound, or change
FIN, ORDER9, or Q36.
