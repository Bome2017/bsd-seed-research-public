## Proposition 1

For p ∈ D, the following are equivalent:
1. dim_Fp X_p <= 1;
2. X_p = 0;
3. ν_p = 1, i.e. some one-prime derived Heegner class κ_ℓ is nonzero in H^1(K, E[p]);
4. the augmentation image Θ_1(0) ⊗ F_p of the first Euler-system ideal is the unit ideal.

Statement 4 needs p good ordinary, and "augmentation image" uses Howard's specialization.

### Proof

(c) [1 ⇔ 2 ⇔ 3] We have s⁺ = 2 + dim X_p >= 2 and s⁻ = 1. Apply Lemma 8.4.
- If ν is even, then s⁻ = ν+1 forces ν = 0. Then s⁺ <= 0, a contradiction.
- So ν is odd, and s⁺ = ν+1. Hence dim X_p = ν − 1.
- So dim X_p <= 1 ⇔ ν <= 2 ⇔ ν = 1, because ν is odd. Then dim X_p = 0.

Parity of X_p is not used: the sign in Lemma 8.4 already forces it. This is the record's
`nu_le_two_iff_sha_of_twist` (kernel-checked bookkeeping on top of hypothesis `ZhangLemma84`).

(a) [exact control, H^2 kept] C is perfect with amplitude [1,2] over Λ. H^0 vanishes because
E[p] is irreducible. H^3 is dual to an H^0 of E[p^∞] and vanishes for the same reason. For a
non-zero-divisor T, the triangle C →T C → C⊗^L Λ/T gives

    0 → H^1(C)/T → H^1(C ⊗^L Λ/T) → H^2(C)[T] → 0,
    H^2(C ⊗^L Λ/T) = H^2(C)/T,

and H^i(C ⊗^L Λ/T) = H^i_f(K, T) by Nekovář's control theorem for Greenberg conditions.

(b) [4 ⇔ 3] Howard's Λ-adic Kolyvagin system reduces at T = 0 (and mod p) to the classical
Heegner Kolyvagin system. This is imported at statement level (Howard, Compositio 2004) and was
not re-read here. Thus Θ_1(0) ⊗ F_p is generated by the images of κ_ℓ mod p over Kolyvagin
primes ℓ. It is the unit ideal iff some κ_ℓ ≢ 0 mod p.

The height-two error in Θ_i ≈ Fitt_i plays no role in this direction. Statement 4 is phrased
on the Euler-system side and never passes through a Fitting ideal modulo pseudo-null modules. ∎
