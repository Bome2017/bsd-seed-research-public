This is an abstract module calculation, not an elliptic-curve realization or an assertion about the seed. It isolates the formal inference being tested. Let R=Z_p[[U]], let a>=1 and P=p^a, and take the two-term complex with differential

            [ P  U  0  0 ]
    D(U) =  [ 0  P  U  0 ].
            [ 0  0  0  U ]

Its kernel is free, generated by

    eta=(U^2,-PU,P^2,0)^t.

Indeed the third equation forces the last coordinate to vanish. The second and first equations, using that P and U have no common irreducible factor, successively force the remaining vector to be a multiple of eta. With signed minors defined by (-1)^j times the minor deleting column j (columns numbered from zero), the maximal-minor vector is U eta.

The cokernel splits as Y plus R/(U), where Y is presented by the upper-left 2-by-3 block. Its maximal-minor ideal is (P^2,PU,U^2). These minors generate the unit ideal at every height-one localization, so Y is finite length and

    char_R(coker D)=(U).

    char_R(H^1/Rz)=(U)=char_R(H^2).
