# Whole-source kernel pilot

Question: can we certify what our local detectors miss using a complete candidate source, without feeding their known excess columns into the kernel calculation?

This is a retrospective exact matrix experiment on saved arithmetic, not a blinded run or new descent. At coefficient 3, reconstruct containing spaces from all source columns and necessary scalar, additivity and local rows. For 1913b1 compare the already observed rank-one block at 1867 with the rank-two block at 997; do not use the supplied true-class basis to construct the kernel. Independently enumerate every source vector to validate it. Include certified complete 389a1 and 433a1 controls, and block completeness promotion for 28042a1 and the seed's historical conditional source.

Expected mathematical criterion: if Z=ker(A) intersect ker(D) equals the point plane W in a source containing all Selmer classes, then D has zero kernel on Sel/W. If known admitted classes fill ker(A), they additionally certify completeness of that displayed class list. A nonzero remaining Z/W must be retained, not counted as an extra detected direction. Local detector rows are not Selmer membership constraints and must never be imposed as though true classes must annihilate them.

Kill tests: source dimension or coordinate mismatch; point classes rejected by admission or detectors; missing source certificate; treating finite local checks as sufficient global admission; rebranding already known control groups as new seed results. All three seed endpoints remain unchanged unless separately established.

No claim of a uniform bound. Next experiment candidates must use this pilot to address an actual residual kernel or completeness index, not merely repeat the known-class detection.
