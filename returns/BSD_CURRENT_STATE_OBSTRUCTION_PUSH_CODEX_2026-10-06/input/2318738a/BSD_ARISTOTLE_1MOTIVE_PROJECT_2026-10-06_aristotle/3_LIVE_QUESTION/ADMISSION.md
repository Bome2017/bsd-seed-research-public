# Admission test: a characteristic-zero comparison Θ_E ↔ Z ↔ M_G2 (Claude, Opus 5.5, 2026-10-06)

Assignment: Pro's 10-06 direction, relayed by the user: "construct or rule out a Sha-free characteristic-zero comparison producing the same s_p for all p". Pro's own first test: exhibit an actual map from the Mazur–Tate object to a common line, and from the G2 1-motive to the same line, defined over ℚ or ℤ[1/D] before p is chosen; otherwise stop.

**Best-case endpoint effect, stated before starting.** If admitted, it would give the FIN tail directly: s_p ≡ m together with G2, Theorem W and Ota gives Supp Ш ⊆ B ∪ Supp(num m). Cost: $0, paper only.

**Verdict: `NOT_ADMITTED` at Pro's first test (the arrow Θ_E → common line).** Scope: this verdict covers the arrows that can be written with objects in the record and with the published framework read today (Tan 1995). It is not an impossibility theorem.

## The arrow that exists (M_G2 → line)

- **The line.** L = (∧²E(ℚ))^{⊗2} ⊗ ℚ, generated by ξ = (P₁∧P₂)^{⊗2}.
- **The map.** G2's fixed 1-motive M = [ℤ² → G₁ ×_E G₂] is defined over ℚ before p. Its tame Frobenius invariants give ρ_{p,ℓ}(ξ) = (a_ℓ − 2)·R_{p,ℓ} (G2 (5.5); record candidate K5).
- **Status.** This arrow is in hand.
- **Lineage.** M is the same kind of object Bloch (Invent. Math. 1980) built from the height pairing to restate BSD as a Tamagawa-number identity. Tan 1995 uses the same Mazur–Tate pairing, and G2's normalization follows Tan §2.1–2.2.

## The arrow that is missing (Θ_E → line)

1. **The degree-2 term has no characteristic-zero realization of its own.**
   - At every finite level M the class of θ_M in I²/I³ ⊂ ℤ[G_M] lies in a finite group, so every homomorphism from it to ℚ is zero.
   - So m cannot be read off the degree-2 term. A characteristic-zero m has to come from a construction that combines the integral θ_M (or the L-values L(E,χ,1) they interpolate) with the Mordell–Weil side. That is a reciprocity law, not a projection.
2. **The only characteristic-zero lifts on record or in print:**
   - **(a) Archimedean.** Read m off L″(E,1). This is TAC (m = 8q), which needs q ∈ ℚ, i.e. RAT. Tame and archimedean directions do not mix: the tame graded pieces are finite and the archimedean tangent direction is a real line. So there is no shortcut map between them.
   - **(b) Motivic.** A rank-two Heegner/Stark element η ∈ ∧²E(ℚ) ⊗ ℚ attached to the L-function. None is constructed over a number field (record C-HEEG; Yun–Zhang is function fields only; plectic points are conjectural over ℚ).
   - **(c) Tan 1995.** This is the published comparison between θ's degree-r term and the Mazur–Tate corrected discriminant.
     - Main theorems 3.12, 3.14, 3.16 need BSD for E over K and over every intermediate field L′/K. Tan notes this assumption seems unavoidable unless one expects to prove something about BSD itself.
     - Even then, for cyclic G the formula holds only up to an undetermined nonzero constant in F_p^×.
     - So (c) is circular for FIN, and it does not give the exact normalization Pro's test requires.
3. **The first failure, precisely.** No arrow Θ_E → L over ℚ or ℤ[1/D] can be written from these objects without importing (a) RAT + TAC, (b) a rank-two global element that does not exist yet, or (c) BSD over the intermediate fields.

## What would change this

Any one of these:
- a new characteristic-zero element η ∈ ∧²E(ℚ) ⊗ ℚ whose tame realizations are θ's degree-2 terms (the rank-two analogue of the Heegner point's role in rank one);
- an unconditional proof of Tan's comparison over the degree-p subfields of ℚ(μ_ℓ) with an exact constant;
- rationality of q together with a tame–archimedean comparison (TAC).
