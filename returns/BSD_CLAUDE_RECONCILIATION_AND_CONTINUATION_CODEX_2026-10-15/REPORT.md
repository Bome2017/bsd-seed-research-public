## 2. Actual continuation: a class with incompatible repairs

The saved, certified number-field data for the -3 twist of389a1 had already been produced before the October13 limit interruption, but neither the old state file nor Claude's summary reflected the unfinished calculation. I reused it without rerunning the expensive class-group certification.

The curve is `y^2+y=x^3-21x-27`, conductor3501, with saved rank0. At coefficient3 its degree-eight point field has ordinary and S-class group `C3`, for `S={3,389}`. This is a genuine nontrivial S-class source; the eight earlier rank-two controls had trivial S-class groups.

For the actual valuation-zero source, write `0 -> U -> H -> C -> 0`, where U is the four-dimensional ordinary-unit space and C is the one-dimensional ordinary class boundary. Let G be scalar compatibility plus the specified necessary global additivity rows, and L the local-Kummer rows. These are computed from actual field elements and local points.

For a fixed nonzero class lift beta, the computed repairs are

    u_G = (0,1,2,2),       u_L = (2,2,2,2).

Both marginal screens admit beta. Their repair difference is

    u_G-u_L = (1,2,0,0).

The appropriate, choice-independent obstruction is

    omega(c) = [u_G-u_L] in U/(ker(G|U)+ker(L|U)),

defined on the class directions that admit both marginal repairs. A common repair exists if and only if omega(c)=0. Here both unit kernels vanish, and the displayed obstruction is nonzero. In the eight rank-two controls the computed obstruction is zero.

This is not only an elimination-rank claim. In coordinates `(u1,u2,u3,u4,c)`, four necessary arithmetic rows satisfy

    G[7] + G[12] + G[44] + 2 L_3[1] = (0,0,0,0,1)  over F3.

Thus this is the arithmetic identity `c = s + a_127 + a_151 + 2*l_3` on the displayed source, and every simultaneously admitted element has `c=0`. The exact torsion triples and field embeddings are recorded in the row-map review. The full eleven-dimensional source has zero joint kernel as well, so discarded valuation directions do not explain the result.
