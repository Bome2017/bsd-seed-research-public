## 6A. Addendum (2026-10-07): the tightened threshold

The acceptance rule has been tightened. `DERIVED_GROSS_IDENTITY` now needs **all four** of:
1. a characteristic-zero degree-two identity;
2. one fixed m_E ∈ ℚ^×, free of Ш, FIN, Q36 and BSD, **proved** non-zero, with explicit denominator, and the same rational number at every auxiliary level;
3. both specialization maps, Θ^{(2)} → C₂(p,ℓ) and det h → (a_ℓ − 2)·R_{p,ℓ}, with compatible normalizations that do not depend on p or ℓ;
4. one explicit finite exceptional set S, giving Ш[p] ≠ 0 ⇒ p ∣ num(m_E) outside S.

Level-dependent m_{E,ℓ}, p-adic units and "up to unit" constants give `NO_DEGREE2_IDENTITY`, `REDUCTION_TO_ONE_NEW_THEOREM`, or the new status `IDENTITY_ONLY_UP_TO_P_UNIT`.

**The status stays `PRECISE_OBSTRUCTION`.** This run produced no identity at all, not even a unit-ambiguous or level-dependent one. So none of the three weaker statuses describes it. The checklist below records where each route fails.

### 6A.1 The threshold itself (PROVED, `DerivedGross/Threshold.lean`)
- **`dvd_num_of_fixed_constant`.** Inputs:
  - one m = a/b;
  - one set S;
  - for every prime p ∉ S, the congruence b·C₂ ≡ a·D (mod p), where D = (a_ℓ − 2)·R_{p,ℓ} for a G2-admissible ℓ = ℓ_p;
  - D ≢ 0 (from G2);
  - the detector Ш[p] ≠ 0 ⇒ C₂ ≡ 0 (Ota).

  Conclusion: Ш[p] ≠ 0 ⇒ p ∣ a for every p ∉ S.
- **`support_finite_of_fixed_constant`.** If in addition a ≠ 0 and S is finite, the support of Ш is finite.
- So interfaces 1–4 together are exactly enough for finite support. The deduction itself is formal; the four interfaces are the only content.

### 6A.2 Where units are harmless and where they are not (PROVED)
- **`single_unit_zero_iff`.** If s_p = u_p·m with u_p ≢ 0, then s_p ≡ 0 ⇔ m ≡ 0. This is the user's first case: harmless for support detection.
- **`two_units_detection`.** This refines the user's second case.
  - Suppose X = m·Y holds in one common target, and the two specializations give C = u·X and D = v·Y.
  - If both u and v are *proved* non-zero mod p, zero/non-zero detection still survives: C ≡ 0 ⇔ m·D ≡ 0.
  - What is lost is the value: C·v = u·m·D, so the specialized scalar is u·m/v, not m. Such a result does not establish the global normalization (interface 3). It does still feed the support argument.
- **`nonunit_vertical_breaks`.** If a vertical factor is only *assumed* to be a unit and is not proved non-zero mod p, the detector can fire while m ≢ 0 and D ≢ 0. Then the bridge fails outright.
- **`level_dependent_no_bound`.** Take m_{E,ℓ} = ℓ and ℓ_p = p.
  - Every per-prime hypothesis of 6A.1 then holds with "every prime is in the support".
  - So a level-dependent constant gives no finite-support conclusion, even though each m_{E,ℓ} is a non-zero rational.
  - This is why requirement 2 says *one* rational number at every level.
- **Rule for future returns.** Each unit in a return should be classified as one of:
  - (i) one unit on the final congruence, proved non-zero;
  - (ii) two vertical units, both proved non-zero;
  - (iii) a factor not proved non-zero.

  (i) and (ii) support `IDENTITY_ONLY_UP_TO_P_UNIT`, and are enough for support detection. (iii) does not establish the bridge.
