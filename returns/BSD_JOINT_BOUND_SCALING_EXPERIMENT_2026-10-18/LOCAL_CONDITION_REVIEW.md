# Local coefficient-prime condition: derivation to be matched to arithmetic

Written deduction, conditional on the retained ordinary representation and source normalization. This is NOT a computed row and supplies no new bound by itself.

For the control389a1 at7, the retained exact point count gives #E(F7)=13. The ordinary quotient V^- of V=E[7] is an unramified line with nontrivial Frobenius character (trace a7=-5=2mod7); V^+ is the formal torsion line, with character cyclotomic times the inverse quotient character.

The Kummer image E(Q7)/7 is H1(Q7,V^+) inside H1(Q7,V). Indeed nonanomalous reduction allows every completed point class to be represented in the formal group. A division point can then be chosen in the formal group, giving a V^+-valued cocycle. Both spaces have dimension1: the source has rank1; H0(V^-)=0 and H2(V^+)=H0(V^-)^vee=0, while local Euler characteristic gives dimH1(V^+)=1. This also proves the injection from H1(V^+) into H1(V).

Choose a nonzero formal torsion point T. Its local field K=Q7(T) has degree6, prime to7, in the retained field data's tame(e,f)=(6,1) branch. The Weil pairing map V -> mu7, P -> e7(P,T), has kernel V^+ and identifies V^- restricted to K with mu7. Restriction in H1(V^-) from Q7 to K is injective because its restriction-corestriction composition is multiplication by6. Thus a genuine global cohomology class has Kummer localization exactly when its source evaluation at T is trivial in K^*/K^{*7}.

In particular local seventh-power testing on this branch is a necessary condition on every true Selmer source, even when the containing scalar source is larger than genuine cohomology. A safe larger local allowance is sufficient for upper bounds; a smaller unverified allowance is not.

The degree6 branch, source evaluation orientation, and finite-precision local power test must be matched explicitly before a numerical row is admitted. No row is supplied by this file.
