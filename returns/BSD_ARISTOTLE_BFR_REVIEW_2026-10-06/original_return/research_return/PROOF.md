## Step 1. Local structure at p

[Imp-5] (formal group, e.g. Silverman AEC IV.6.4 and VII.2.2) says the following. For
`p ≥ 3` and the minimal model, the formal logarithm gives an isomorphism
`E₁(ℚ_p) ≅ (pℤ_p, +)` under which `E_n(ℚ_p)` corresponds to `p^n ℤ_p`. A point of
`E₁ \ E₂` corresponds to an element of exact valuation one, which is a topological generator
of `E₁`. In particular `E₁(ℚ_p)` is torsion-free.

[Imp-6] (AEC VII.6) gives the exact sequences

    0 → E₀(ℚ_p) → E(ℚ_p) → Φ(𝔽_p) → 0,   #Φ(𝔽_p) = c_p,
    0 → E₁(ℚ_p) → E₀(ℚ_p) → Ẽ_ns(𝔽_p) → 0.

**1a. The point `R_p`.** By [Lean: `exists_sqrt_dp_padic`] there is `s ∈ ℤ_p` with
`s² = d_p` and `‖s‖ = 1`. By [Lean: `Rp_padic`] the point `R_p = (p⁻², s p⁻³)` lies in
`E(ℚ_p)`, with `‖x‖ = p²` and `t(R_p) = −x/y = −p/s` of norm `p⁻¹`. So `R_p ∈ E₁ \ E₂`, and
by [Imp-5] it topologically generates `E₁(ℚ_p)`. The same holds for `−R_p`, which is the image
under the other embedding (`−s` is also a unit square root).

**1b. `p = 2243` or `5843` (Lemma L(i)).** The index `[E(ℚ_p) : E₁(ℚ_p)] = c_p·#Ẽ_ns(𝔽_p)`
equals `1·2242` and `2·5844` respectively. Neither is divisible by `p`
[Lean: `Local.index_coprime`; Chk-2]. Write `G = E(ℚ_p)/E₁(ℚ_p)`, a finite group of order
prime to `p`. Apply the snake lemma to multiplication by `p` on
`0 → E₁ → E(ℚ_p) → G → 0`. Since `G[p] = 0 = G/pG`, this gives
`E₁/pE₁ ≅ E(ℚ_p)/pE(ℚ_p)`. The left side is `pℤ_p/p²ℤ_p ≅ ℤ/p`, generated by `R_p` (1a).
So `E(ℚ_p)/p` is one-dimensional and spanned by the class of `R_p` (or of `−R_p`).

**1c. `p = 4547` (Lemma L(ii), (iii)).** Here `c_p = 2` and `Ẽ_ns(𝔽_p) ≅ 𝔾_a(𝔽_p) ≅ ℤ/p`,
since the reduction is a cusp [Chk-2: singular point `x ≡ 1516`, tangent-cone coefficient 0,
`#Ẽ_ns = 4547`].

* `P1 ≡ (1516, 0)` is the singular point, so `P1 ∉ E₀`. `P2 ≡ (2153, 4153)` is a nonsingular
  affine point, so `P2 ∈ E₀ \ E₁` [Chk-1; Lean: `Local.chainCert_true` includes `2y(P2) ≢ 0`].
* Put `A = (p−1)P2` and `Z = pP2`. Since `E₀/E₁ ≅ ℤ/p`, we have `Z ∈ E₁` and
  `A = Z + (−P2)`. Near `−P2`, which reduces to a nonsingular point with
  `y(−P2) ≢ 0 (mod p)`, translation by `Z ∈ E₁` changes `x` as follows:
  `x(Z + (−P2)) − x(−P2) = 2y(−P2)·t(Z) + (terms of t-degree ≥ 2 with p-integral
  coefficients)`. This follows because the invariant differential is `dx/(2y) = (1 + O(t))dt`
  and translation by an integral point of `E₀` is given by integral power series. Hence
  `v_p(x(A) − x(P2)) = v_p(t(Z))`. [Imp-7: standard formal-group translation identity.]
* The certificate computes `(p−1)P2` exactly modulo `p³` in projective coordinates (Lean,
  kernel-evaluated) and modulo `p⁸` in affine coordinates (Python, independent). It checks
  that every chord denominator is a `p`-adic unit (so no precision is lost), that `A` has unit
  `Z`-coordinate, and that `v_p(x(A) − x(P2)) = 1`. Both implementations give
  `(x(A) − x(P2))/p ≡ 1274 (mod p)` [Lean: `Local.chainCert_true`; Chk-1].
* Hence `v_p(t(pP2)) = 1`. By [Imp-5], `pP2` topologically generates `E₁(ℚ_p)`. Let `H` be
  the closed subgroup generated by `P2`. Then `H` contains `E₁`, and `H` maps onto `E₀/E₁`
  (the image of `P2` is nonzero in `ℤ/p`). So `H = E₀(ℚ_p)`. Since `H` is procyclic and
  `pH ⊇ ⟨pP2⟩ = E₁` with `[H : pH] ≤ p = [E₀ : E₁]`, we get `E₁ = pE₀`. Also `E₀` is an
  extension of `ℤ/p` by `ℤ_p`, so it is pro-`p`. It is procyclic, so it is a quotient of
  `ℤ_p`. It is infinite, so `E₀ ≅ ℤ_p`, which is torsion-free.
* `[E(ℚ_p) : E₀(ℚ_p)] = 2` is prime to `p`. The snake-lemma argument of 1b therefore gives
  `E(ℚ_p)/p ≅ E₀/pE₀ = E₀/E₁ ≅ ℤ/p`, spanned by `P2`, and `E(ℚ_p)[p] = 0`.
* Finally `R_p ∈ E₁ = pE₀ ⊂ pE(ℚ_p)`, so its local Kummer class is zero. This is
  Lemma L(iii).

## Step 2. Global field structure and the kernel of restriction

Let `K_p = ℚ(E[p])`, `F_p = ℚ(√d_p)` and `K'_p = K_p F_p`.

* `F_p` is a quadratic field, because `d_p < 0` [Lean: `dp_neg`, `dp_not_sq`].
* By [Imp-1], `Gal(K_p/ℚ) = GL₂(𝔽_p)`. Its abelianization for `p ≥ 5` is `det: 𝔽_p^×`.
  Since `det ρ̄` is the mod-`p` cyclotomic character, the unique quadratic subfield of `K_p`
  is `ℚ(√p*)` with `p* = ±p`. By [Lean: `dp_mul_p_not_sq`], `d_p·(±p)` is not a rational
  square, so `F_p ≠ ℚ(√p*)` and `F_p ∩ K_p = ℚ`. Hence
  `G₀ := Gal(K'_p/ℚ) = GL₂(𝔽_p) × C₂`.
* The central element `(−I, 1)` acts by `−1` on `V` and on `Vε` (where `ε` is the character
  of `F_p`). Inner automorphisms act trivially on cohomology, and 2 is invertible, so
  `H^i(G₀, V) = H^i(G₀, Vε) = 0` for all `i`.
* Let `κ₁`, `κ₂` and `r` be the Kummer cocycles of `Q1`, `Q2` and `Q3`. Restricted to
  `G_{K'_p}`, they give a `G₀`-equivariant injection of `P := Gal(L_p/K'_p)` into
  `V ⊕ V ⊕ Vε`. The third factor is twisted because the conjugate of `R_p` is `−R_p`.
  Being a direct sum of simple modules, `V ⊕ V ⊕ Vε` is a semisimple `G₀`-module, and so is
  `P`.
* **The projection of `P` to `V ⊕ V` is onto.** Otherwise there would be a nonzero
  equivariant `φ = (a, b): V ⊕ V → V` killing it, using semisimplicity and
  `End_{G₀}(V) = 𝔽_p`. Then `aκ₁ + bκ₂` vanishes on `G_{K'_p}`. Since `H¹(G₀, V) = 0`, the
  class of `aP1 + bP2` in `H¹(ℚ, V)` would vanish, contradicting `dim W = 2` [Imp-2].
* Hence `P ≅ V² ⊕ U` with `U ∈ {0, Vε}`, and
  `Hom_{G₀}(P, V) = Hom_{G₀}(V², V) ≅ 𝔽_p²`, because `Hom_{G₀}(Vε, V) = 0` (the `C₂`
  factor acts differently). Note that this step does **not** need `r ≠ 0`. The record used
  `r ≠ 0`, proved by localization of `R_p` at `p`, and that argument is unavailable at
  `p = 4547` by L(iii).
* Inflation–restriction for `1 → P → Γ_p → G₀ → 1`, with `P` acting trivially on `V` and
  `H¹(G₀, V) = H²(G₀, V) = 0`, gives `H¹(Γ_p, V) ≅ Hom_{G₀}(P, V) = 𝔽_p²`. This group is
  spanned by `κ₁` and `κ₂`. Inflation–restriction for `G_ℚ → Γ_p` (with `V^{G_{L_p}} = V`)
  then gives

      ker[H¹(ℚ, V) → H¹(L_p, V)] = H¹(Γ_p, V) = W.                         (★)

## Step 3. Restricted Selmer classes factor through A_p

Let `σ ∈ Sel_p(E/ℚ)`. Its restriction is a `Γ_p`-equivariant homomorphism
`G_{L_p} → V`, since `E[p] ⊂ E(L_p)`.

* **Finite `q ≠ p`.** We have `p ∤ c_q`, since all Tamagawa numbers are 1 or 2 [Imp-3]. So
  the local Kummer image `E(ℚ_q)/p` equals the image of `E₀(ℚ_q)/p`. These classes are
  unramified [Imp-8]. Indeed, for `P ∈ E₀(ℚ_q)`, the fibre of `[p]` over `P` in the identity
  component of the Néron model is étale over `ℤ_q` (`q ≠ p`), and its special fibre has
  points over `𝔽̄_q` because the connected smooth special fibre is `p`-divisible over `𝔽̄_q`.
  By Hensel's lemma, `P/p` is defined over `ℚ_q^ur`. So `σ|_{I_q}` is a coboundary. On the
  inertia groups of `L_p` above `q`, which act trivially on `V`, it is therefore zero. This
  holds even where `L_p/ℚ` ramifies (for example at primes dividing `d_p`, or at `q` with
  `E[p]` ramified).
* **At `p`.** `σ_p` lies in `E(ℚ_p)/p`. This group is spanned by `R_p` (or `−R_p`) when
  `p ∈ {2243, 5843}`, and by `P2` when `p = 4547` (Step 1). The corresponding `p`-division
  point (`Q3` resp. `Q2`, or its negative) is rational over every completion `L_{p,w}`. So the
  Kummer class restricts to zero on every decomposition group of `L_p` above `p`. For `R_p`,
  `w` determines an embedding `F_p → ℚ_p` (`p` splits [Lean: `exists_sqrt_dp_padic`]); either
  embedding sends `R_p` to a local generator by 1a and 1b.
* **Archimedean places.** These give no odd-primary obstruction.

So `res(σ)` factors through the Galois group of the maximal abelian exponent-`p` extension of
`L_p` that is unramified at all finite places and split at all places above `p`. By class
field theory [Imp-9] this Galois group is `Cl(O_{L_p}[1/p])/p = A_p`. Equivariance places
`res(σ)` in `B_p`.

## Step 4. Conclusion

The map `Sel_p(E/ℚ) → B_p` has kernel `Sel_p ∩ W = W` by (★). Since `Sha[p] = Sel_p/W`
(Kummer sequence), the induced map `Sha(E/ℚ)[p] ↪ B_p` is injective. This proves Theorem BFR.

**(a)** Choose an `𝔽_p`-basis `f_1, …, f_{s_p}` of the image of `Sha[p]` in `B_p`. Then
`(f_i): A_p → V^{s_p}` is `Γ_p`-equivariant. Its image is a submodule of the semisimple
module `V^{s_p}`. If it were proper, there would be a nonzero equivariant map
`V^{s_p} → V` killing it. That map has the form `Σ a_i·id` because `End(V) = 𝔽_p`, and then
`Σ a_i f_i = 0`, a contradiction. So `A_p` surjects onto `V^{s_p}`, a group of order
`p^{2 s_p}`, and `p^{2 s_p}` divides `#A_p`, which divides `#Cl(O_{L_p}[1/p])`.

**(b)** If `dim B_p ≤ 1` then `s_p ≤ 1`. If `p⁴ ∤ #Cl` then `s_p ≤ 1` by (a). By [Imp-4]
`s_p` is even, so `s_p = 0`. Hence `Sha[p] = 0`, and since `Sha[p^∞]` is `p`-primary torsion,
`Sha[p^∞] = 0`. ∎
