## 2. The class experiment after that repair

A sealed panel used 64 new database rank-two representatives beyond conductor 1627 with good reduction at 3. Five fall outside the irreducible degree-eight torsion-field setup and were rejected. Among 59 accepted provisional field calculations, 45 had no 3-class direction and 14 had one. None had two. These are selection outputs from `bnfinit`, not certified upper bounds for all 59 fields.

An explicitly recorded adaptation stayed within the same panel: a one-dimensional faithful class not supplied by the known points would also be useful. Exact point evaluations and ideal-class coordinates in the provisional presentations showed point-image rank 1 in all 14 cases. Therefore this panel furnished no unused class direction on which to test a new rejecting map. The point list can include rational torsion; its displayed coordinate count is not an independently established Mordell–Weil rank.

The first new case, 1664n1, was taken through actual source certification and exact incidence arithmetic. Its ordinary source class group is C6, with faithful 3-part C3; the target class group is also C6. The actual class map on that 3-part is zero and the connecting obstruction is zero, authenticated by ideal equalities and a literal cube identity. The actual map on the four-dimensional ordinary unit space has rank 3 modulo 3. Combining its one-dimensional kernel with the one-dimensional class kernel and zero connecting obstruction gives

\[
\dim_{\mathbf F_3}\ker\bigl(u:A(\varnothing,3)\to B(\varnothing,3)\bigr)=(4-3)+1=2.
\]

This is a **new complete ordinary-source bound for this control**, obtained from certified unit and ideal-class arithmetic rather than a supplied Selmer/Sha answer. It includes the class-supported contribution. It is not a new class-rejection mechanism: the class direction survives and is occupied by a rational point.

The additional valuation check closes the remaining source term in this example. For S={2,3,13}, negation fixes every source prime over S (respectively one, one, and two primes). Hence the faithful minus valuation sector is zero. Every faithful S-virtual-unit class is ordinary, and

\[
\dim_{\mathbf F_3}\ker\bigl(u:A(S,3)^-\to B(S,3)\bigr)\le2.
\]

The published Schaefer–Stoll descent injection identifies this as a containing source for the classical 3-Selmer group; its source map and support are matched in [SOURCE_APPLICATION.md](class_map/SOURCE_APPLICATION.md). With the retained rank-two input, the control's 3-Selmer group is therefore exactly its point plane and its 3-primary Sha vanishes. This is a complete finite **control** bound. The original seed is a different curve, and the coefficient-three calculation does not establish growing norm rank or class control as the coefficient prime grows. ## 3. The partial-relation experiment

The saved weighted search retained 14,326 exact norms and reconstruction coordinates, not all element vectors. A batch-GCD screen found 5,519 norms with shared residual factors after removing primes at most 1000. It selected 80 candidates by a sealed score and reconstructed those 80 elements, matching every saved norm exactly. Four overlap the earlier excluded 20; 76 are newly inspected.

Every selected element has a proved rational prime occurring exactly once in its norm and absent from every other saved norm. The corresponding actual prime ideal is distinct from its negation conjugate. Thus each relative ratio retains a private anti-divisor coordinate; rational norm overlap elsewhere cannot cancel it.

All six scalar images of these 80 primes were checked. Their disjoint blocks give divisor rank 240 for 480 translated ratios and faithful projected rank 80 for 80 columns. Exact inverse identities account for the integer relations: the only ordinary-unit product in this selected scalar family is 1. The subgroup is also seventh-power saturated under the retained real-embedding input, so field seventh roots do not repair it. [Proof](partial_relations/PROOF.md).

These pivots made full ideal factorizations unnecessary; no incomplete factorization was accepted as a positive unit certificate. About 30.9 seconds of producer arithmetic sufficed. No element reached the norm/local evaluator, so no new rejection rank or complete unit-kernel bound was obtained. The other 14,246 element vectors were not reconstructed.

## 4. What the experiments decide

- The selected partial-relation family fails even with its scalar closure; widening the old manipulation of those elements is not a continuation.
- The new class panel does not supply the missing class-rejection contrast: every visible faithful class is already point-occupied. The certified 1664 instance nevertheless supplies a complete source upper bound of 2, including the class term and the zero faithful valuation allowance.
- Neither result bounds the original seed's undiscovered units or ordinary class contribution, or supplies a theorem across coefficient primes.

The complete-source problem still requires both contributions. For the current coefficient-seven control, the unit space has dimension 4, and the class contribution must be bounded after compatible unit corrections; a partial unit list, provisional class presentation, or finite failure is not such a bound.

The useful positive result is a complete rank-two control where a nonzero class contribution survives but the total source is still small enough. A possible continuation must explain why the combination of unit rank, class kernel and valuation allowance stays small on the original seed and as p grows. This run supplies one fully calculated profile for that question, not a theorem asserting it persists. No larger search is launched by this report.
