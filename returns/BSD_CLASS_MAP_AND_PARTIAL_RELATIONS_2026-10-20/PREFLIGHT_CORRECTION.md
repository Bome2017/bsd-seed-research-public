# Correction to the proposed discriminating control

The prior recommendation treated the mirror389 incidence class-map value as an open possibility. Reading the complete October15 norm certificate shows that its sole ordinary class already has a virtual-unit lift with literal cube norm. Therefore its image under the ordinary class map is necessarily zero.

Indeed, let div(alpha)=pD and u(alpha)=gamma^p. Compatibility of the actual incidence divisor and element maps gives p*u_D(D)=p*div(gamma). The divisor group is torsion-free, hence u_D(D)=div(gamma). Thus u_C([D])=0. Existence of this norm-zero lift also kills its connecting obstruction. A local obstruction can still reject every global lift.

Since the retained class group is C3 and this is its generator, the full class map and connecting obstruction vanish on this control. The same argument applies to a class direction already furnished by a rational-point or other authenticated norm-cube lift.

Fresh ideal arithmetic is useful as authentication but cannot be claimed as a newly discriminating finding or a new class bound here. Lane A is instructed to seek an untested faithful class direction before extending calculations. Nonfaithful class calculations are not a substitute.

This corrects our recommendation; it is not evidence against ideal-class kernel bounds in general.
