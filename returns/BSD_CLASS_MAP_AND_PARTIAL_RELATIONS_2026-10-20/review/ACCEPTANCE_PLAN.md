# Independent execution review: acceptance plan

Date: 2026-10-20. Scope: the two bounded execution lanes, not independent recertification of retained field/rank/elliptic-image inputs or an external novelty review.

## Correction to the proposed class control

For an authenticated virtual-unit representative alpha with div(alpha)=pD and literal incidence norm u(alpha)=gamma^p, compatibility yields p*u_D(D)=p*div(gamma). The divisor group is free abelian, hence u_D(D)=div(gamma). Thus its class image is zero. The same norm-zero lift witnesses the vanishing connecting obstruction. Mirror389's retained C3 generator therefore cannot be a fresh test of nonzero incidence class-map rank. Its local rejection remains compatible with both vanishing global obstructions. New calculation of that map is authentication only.

## Class lane acceptance

1. Verify sealed panel and input hashes; verify full-field degree and actual negation automorphism rather than selecting by total class-group size alone.
2. Treat bnfinit output and the faithful eigenspace calculated from it as selection data until certified. A bounded panel with no candidate is not a theorem that no suitable source exists.
3. On a candidate, distinguish complete source certification, exact I^p=(beta), literal incidence map of beta, divisibility of its divisor by p, and target ideal-class evaluation. An exit status or empty log is not certification.
4. Record whether rejection is by the class map, its connecting map, or incompatible global/local unit repair. Ranks on known classes do not bound undiscovered classes.
5. Any upper bound must retain unit and valuation contributions. A class calculation on a control is not original seed FIN.

## Partial-relation acceptance

1. Norm factor overlaps are selection hints only. Principal ideal divisors, not rational norms, determine cancellation.
2. Reconstruct every admitted vector from the retained field, ideal, weight and LLL conventions; require exact saved norm equality. Distinguish all 14,326 norm rows from the much smaller reconstructed element panel.
3. Require complete factorization and exact ideal-product reconstruction for every admitted divisor. Include all support, retaining HNF identities and scalar/tau actions.
4. Integer-kernel vectors produce candidate ordinary units only after exact element and inverse integrality. Mod-seven divisor divisibility alone produces virtual units, not ordinary units. A faithful projection of a nonunit is not an ordinary unit certificate.
5. Reject identity/torsion before claiming nonzero units. Passing to a nonzero class modulo seventh powers requires an authenticated test; an element nontrivial in the field may still have trivial unit class modulo seven.
6. Only authenticated faithful unit classes may enter norm/local rejection matrices. Zero output from a bounded candidate family says nothing about the entire unit space or class contribution.
