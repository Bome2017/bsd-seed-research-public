# Coverage of the unrestricted relative-unit construction

This elementary observation concerns the source family, not the bounded search or its output rank.

Let A be the actual point field, tau its scalar -1 involution, and O_A its integer ring. Every accepted alpha in a tau-stable integral principal ideal I=(alpha) gives an ordinary unit

\[
\epsilon=\alpha/\tau(\alpha),\qquad \epsilon\tau(\epsilon)=1.
\]

Conversely, suppose epsilon is an ordinary norm-one unit and epsilon is not -1. Set alpha=1+epsilon. Then alpha is a nonzero algebraic integer and

\[
\tau(\alpha)=1+\epsilon^{-1}=\epsilon^{-1}\alpha.
\]

Since epsilon is a unit, the principal ideal (alpha) is tau-stable, and alpha/tau(alpha)=epsilon. Thus every such relative unit belongs to the unrestricted stable-principal-ideal construction. This is an explicit identity and does not require an imported Hilbert-90 theorem. The exceptional unit -1 is a seventh power, so it contributes no class to the current quotient.

There is also no faithful-character loss from restricting ordinary units to relative units. For any ordinary unit u, its ratio u/tau(u) has relative norm one. In the additive notation for O_A^*/O_A^{*7}, the faithful projector satisfies e_chi tau=-e_chi. Hence

\[
e_\chi[u/\tau(u)]=2e_\chi[u].
\]

Since 2 is invertible modulo 7, projections of relative norm-one units span the entire faithful ordinary-unit component. The same calculation works at any odd coefficient prime with an odd scalar character.

This prevents an intrinsic parity loss like that of the earlier central-fixed sources. It does **not** bound the norm of a required stable ideal, guarantee that a bounded weighted search finds its generator, bound an index of discovered units, or control the ordinary class contribution. The actual rank test remains necessary. The lemma gives no seed endpoint or across-prime bound.
