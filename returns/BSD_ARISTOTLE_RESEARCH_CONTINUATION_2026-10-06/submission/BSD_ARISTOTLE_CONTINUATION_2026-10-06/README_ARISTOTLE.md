The upload ZIP contains this directory. The correct project root is the one
containing TASK.md, directly here; there is no additional project/ layer.

The new TASK.md governs the continuation. The earlier root task is preserved
in historical_task/. The unchanged full reading ZIP and all original direct
compendium/map/index files remain supplied. The checked BFR return and its
corrections are exposed at accepted/BSD_ARISTOTLE_BFR_REVIEW_2026-10-06/ by
prepare_latest_review.py. Its full original review ZIP is in payload/.

Use SUBMISSION_PROMPT.txt as the instruction with this project, or use the
command in SUBMIT_COMMAND.txt from this directory. That command launches a
real job and is supplied for the user; preparation does not execute it.
The pinned interface is documented at https://pypi.org/project/aristotlelib/2.1.0/.
No API key or account credential is included.

Aristotle should run prepare_reference.py and prepare_latest_review.py after
startup to expose the original 5,180-entry reading set and 64-entry review. Do not expand it inside the upload directory before
submission: doing so duplicates the context in the input archive. A temporary
local extraction is used for preparation checks instead.

This is a research continuation, not a completed BSD proof and not a claim that
a newly successful bound mechanism has been discovered by the task designer.
The first job demonstrated useful construction and formal-arithmetic work; the
new task changes what it should spend its next work on. It permits useful
partial results and changing methods.

The 283,307-object preservation archive and bulk raw evidence are not all in
this project. Their path/hash/capture indexes remain included. No stronger
completeness or exhaustive-reading claim is made. Historical inputs keep their
own grades, versions and formal trust boundaries.
