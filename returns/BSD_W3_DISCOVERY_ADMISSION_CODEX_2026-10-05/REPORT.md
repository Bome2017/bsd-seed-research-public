# W3 discovery experiment: admission check

**NOT_ADMITTED_SOURCE_CONSTRUCTOR_MISSING — stopped at the first gate.**

The proposed empirical search requires genuine weight-five/six seed symbols modulo the specified powers of p. The existing `symbol_values.py` performs the final weighted sums **after those symbols are supplied**. Its source and input contract say explicitly that it neither constructs the Hida forms nor authenticates their symbols. The current return records no seed symbols, no seed values, and no demonstrated affordable evaluator.

I read the four-value implementation, extraction proof, contract and state; checked the preceding Hida/cohomological returns; and searched the relevant W3/weight-three return files for source tables or constructors. The genuine calibration uses Delta at level one. The other reconstruction controls are synthetic. Neither can be substituted for rank-two seed data. This was a targeted W3 inspection, not a claim to have searched every file on the computer.

The arithmetic input is substantial: the two forms are actual Hida specializations, not the seed's weight-two form, at tame conductor 6503188012738584. The retained domain also excludes divisors of a fixed Hida exceptional integer that has not been numerically enumerated. This establishes no complexity lower bound and does not prove that an inexpensive method is impossible. It establishes that the submitted campaign has no demonstrated seed input producer in the inspected material.

**Seed sample produced: zero. No statistical search or control-curve campaign was launched.** There is no new BSD result. I stopped here instead of building a dataset framework around missing values.

Two corrections must survive if a genuine input producer becomes available:

- Keep V_i/p^2 modulo p^2, not merely modulo p. A valuation-three value has zero first residual digit and still passes the p^4 nonvanishing criterion. A zero residue modulo p^4 means valuation at least four, not exactly four.
- The matrix in proposed E4 must be specified from independent arithmetic data before fitting its output. If both a two-coordinate input vector l and a four-coordinate output V are nonzero, a full-column-rank matrix M with Ml=V can always be manufactured by extending l and V to bases. Thus a fitted full-rank M is not an explanatory identity. Even an independently derived full-rank identity would still need separate control of simultaneous local-log vanishing; it does not itself prove a finite exceptional set.

No claim is made that experimental discovery is a dead end, or that W3 is refuted. Admission would change if one genuine seed weight-five/six source table with its branch, integral normalization, domain evidence and measured acquisition cost were actually supplied or constructed. A formula consuming that table is not that construction.

FIN, ORDER9 and Q36 remain open. This is an execution/readiness decision, not a new theorem or another research lane.
