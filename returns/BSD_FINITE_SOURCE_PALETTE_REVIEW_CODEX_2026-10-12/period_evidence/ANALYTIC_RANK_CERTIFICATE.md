## 3. Proof

**Step 1: L(E,1) = 0.**
- P₁ has infinite order: y(P₁) ≠ 0 and the torsion is Z/2 = {O, (0,0)}. So rank E(Q) ≥ 1. The merged Zywina result gives rank 2.
- E is modular (Wiles; Taylor–Wiles; Breuil–Conrad–Diamond–Taylor).
- By the Gross–Zagier–Kolyvagin theorem in the analytic-rank-0 case, L(E,1) ≠ 0 would force E(Q) to be finite.
- Hence L(E,1) = 0.

**Step 2: L′(E,1) = 0.**
- Set Λ(s) = N^{s/2}(2π)^{−s}Γ(s)L(E,s). Then Λ(s) = wΛ(2−s) with w = +1.
- Differentiating at s = 1 gives Λ′(1) = −Λ′(1), so Λ′(1) = 0.
- Since L(E,1) = 0, Λ′(1) = (√N/2π)·L′(E,1). Therefore L′(E,1) = 0.

**Step 3: the G₂ series.** Let f = Σ a_n qⁿ be the newform of E.
- The Fricke involution acts by ε_N = −w. Splitting the Mellin integral at t = 1 gives
  Λ(s) = Σ_n a_n ∫₁^∞ e^{−x_n t}(t^{s−1} + w t^{1−s}) dt, with x_n = 2πn/√N.
- Differentiate twice at s = 1 with w = +1, using d²/ds²(t^{s−1} + t^{1−s})|_{s=1} = 2(log t)²:
  Λ″(1) = 2Σ a_n ∫₁^∞ e^{−x_n t}(log t)² dt.
- Integration by parts gives ∫₁^∞ e^{−xt}(log t)² dt = (2/x)·G₂(x), where G₂(x) = ∫₁^∞ e^{−xy} log y dy/y.
- Since L(1) = L′(1) = 0, Λ″(1) = (√N/2π)·L″(1). Hence

      L″(E,1)/2 = 2 Σ_{n≥1} (a_n/n) G₂(2πn/√N).

- This is Cremona, *Algorithms*, §2.13 (Buhler–Gross–Zagier) with r = 2, and it was re-derived in Lane 3 A2_FORMULA.
- All interchanges are justified by absolute convergence, since |a_n| ≤ d(n)√n and G₂(x) ≤ e^{−x}/x².

**Step 4: coefficients.**
- *a_p for every prime p ≤ T* comes from the independent verifier (`verifier/wverify.c`, 145 lines, integer-only):
  - **Primes p < 4096, and the bad primes 4547 and 5843:** exhaustive point count.
  - **Every other prime:** a checked group-order witness (DESIGN.md O6). The checks are [h]P = O on the twist E_d, a prime-power order certificate D > 2⌊2√q⌋, and exactly one multiple of D in the Hasse interval. These force #E_d(F_q) = h and hence a_q.
- *a_n for n ≤ T* is built by the engine from a_p by multiplicativity: a_{p^{e+1}} = a_p·a_{p^e} − p·a_{p^{e−1}} for good p, and a_{p^e} = a_p^e for bad p.
- The verifier rebuilds a_n independently with a different algorithm: a multiplicative sieve instead of cofactor division.
- **Both Merkle roots of the int64 a_n stream are equal (§6).**

**Step 5: enclosure.** Every term is a ball: π, γ, √N, log, exp, E₁, the G₂ Taylor models and all sums are Arb balls (§4). The tail beyond T is bounded rigorously (§5). The final ball is 2·S_T ± tail_L2(T).

**Step 6.** 0 ∉ [35.929604, 35.941023]. So L″(E,1) ≠ 0 and ord_{s=1} L(E,s) = 2. ∎

## 4. The G₂ evaluator (proof of the enclosure)

**(G1) Series.** G₂(x) = ½(log x + γ)² + π²/12 + Σ_{k≥1} (−1)^k x^k/(k²·k!).
- Let F(s) = x^{−s}Γ(s,x) = ∫₁^∞ e^{−xy}y^{s−1}dy. Then G₂ = F′(0).
- Expand x^{−s}Γ(s) − Σ_k (−1)^k x^{s+k}/(k!(s+k))·x^{−s} at s = 0.

**Direct evaluation, used for x < 1.**
- Stop at the first k ≥ K₀ = ⌊2x_hi⌋ + 4 with |t_k| < 2^{−prec−10}.
- For j > K₀ the term ratio is x·j²/(j+1)³ ≤ x/(j+1) < ½, so the tail is at most 2|t_{k+1}| = 2x^{k+1}/(k+1)!/(k+1)². This is added as a ball radius.

**(G2) Derivatives.** G₂′ = −E₁(x)/x and E₁′ = −e^{−x}/x. The Taylor coefficients at a node x_j are computed by exact power-series algebra in balls:
- the e^{−x} series;

- then integration.

**(G4) Complete monotonicity.** (−1)^k G₂^{(k)}(x) = ∫₁^∞ y^{k−1} log y e^{−xy} dy is positive and decreasing in x.

**Taylor models, used for x ≥ 1.**

## 5. Truncation bound (proved; no BBR constant, no Deligne-type constant)

**Coefficient bound.** Hasse gives |a_p| ≤ 2√p for good p and |a_p| ≤ 1 for bad p. Also a_{p^e} = Σ_{i=0}^{e} α^i β^{e−i} with |α| = |β| = √p. Hence |a_n| ≤ d(n)√n.

**Divisor sums.** D(x) = Σ_{n≤x} d(n) satisfies x log x − x ≤ D(x) ≤ x(1 + log x), from H_n bounds.

**Partial summation.**
- Let g(x) = x^{−1/2}G₂(cx), with c = 2π/√N. Then g is positive and decreasing, and g(x) ≤ x^{−1/2}e^{−cx}/(cx)² since log y/y ≤ y − 1.
- Σ_{n>T} d(n)g(n) = −D(T)g(T) + ∫_T^∞ D(x)(−g′(x))dx ≤ 2T·g(T) + ∫_T^∞ (2 + log x)g(x)dx.
- Therefore

      |L″/2 − 2S_T| ≤ tail_L2(T) = 2e^{−cT} [ 2√T/(cT)² + T^{−1/2}(cT)^{−2} ((log T + 2)/c + 1/(Tc²)) ]

- It is evaluated in Arb at T = 1.5·10⁸: cT = 11.686, and **tail_L2 ≤ 5.709008810·10⁻³** (an upper bound of an Arb ball).
