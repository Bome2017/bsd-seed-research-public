# Exact finite-group checks for the multiplicative valuation calculation

`check_uniform_valuation.py` tested 79 distinct local decomposition-group models and both faithful scalar characters (158 checks). The base prime panel is 5,7,11,13,17,19,29,59, with both signs and a fixed collection of residues including ±1 and the seed's 3,2243,5843. The exceptional (p,q,epsilon)=(487,5843,−1) is computed explicitly as well; it is not extrapolated. That largest case has 729 primitive decomposition orbits in each representation and completed in under one second.

The program generates actual D-orbits on F_p²−{0}, for D generated by the unipotent I and epsilon*diag(q,1). It separately generates the inverse-transpose action on covectors. Each ramification index is computed by enumerating the relevant inertia orbit. For every target representative lambda, all p solutions of lambda(x)=1 are enumerated and assigned to their source D-orbits. Only then is the primitive matrix formed using

    M[Q,P] = e_Q/e_P * #{x in source orbit P : lambda_Q(x)=1}.

Integrality and scalar equivariance are checked. Scalar eigenspaces are constructed from the actual orbit permutations. The measured kernels agree in every case with dimension1 if epsilon*q=1 modulo p, and dimension0 otherwise. The off-formal source channel exists only for epsilon=+1 and maps injectively. This is a statement about the LOCAL PRIME-DIVISOR representation, not the global unit group.

The code retains 96 negative character controls comparing the true matrix with the same incidence counts after deliberately omitting the ramification factors. At p=487,q=5843,epsilon=−1, that omission changes the kernel dimension from1 to0. At p=19 or59,q=2243,epsilon=+1, it preserves total kernel dimension1 but exchanges which channel survives: the correct formal channel has zero image, whereas the unweighted count kills the off-formal channel. Thus total rank alone would fail to detect the normalization error in those cases.

`FINITE_GROUP_CHECKS.json` records the full measured summaries, matrix digests, and complete matrices for p<=7. These are exact checks of a finite panel. The uniform proof and the transport from a seed local representation to these models are separate written arguments. This program supplies no global class bound or FIN conclusion.
